# ChatGPT Tetris for Android

A simple native Android Tetris-style game written in Kotlin.

## Features
- 10 x 20 game board
- Seven tetromino types
- Rotation
- Left/right movement
- Soft drop and hard drop
- Line clearing
- Score system
- Game-over and tap-to-restart
- Touch controls designed for portrait Android phones

## Controls
- Tap: rotate
- Swipe left/right: move
- Swipe down: soft drop
- Long swipe down: hard drop
- Tap after game over: restart

## Open in Android Studio
1. Clone this repository.
2. Open the repository folder in Android Studio.
3. Allow Gradle sync to finish.
4. Run the `app` configuration on an Android emulator or phone.

Minimum Android version: Android 7.0 (API 24).
